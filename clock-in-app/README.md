# ✦ 星光打卡 v2 · 员工打卡 + 管理后台

v2 把软件拆成了两部分：

| 部分 | 谁用 | 能做什么 |
|---|---|---|
| **员工打卡端** | 员工（打卡电脑） | 上班打卡、任务完成打卡、查看自己的考勤和工资、荣誉榜。**不能修改任何东西** |
| **管理后台** | 老板（任何能上网的电脑或手机浏览器） | 实时查看打卡、员工管理、补卡、业绩提成、工资结算、规则设置、操作日志、数据备份 |

所有数据都保存在**服务器**上，打卡时间以**服务器时间**为准，员工改电脑时间没有用。

```
clock-in-app/
├── server/                 ← 服务器程序（放到老板电脑或云服务器上运行）
│   ├── server.js           ← 主程序（只需要 Node.js，不需要安装任何别的东西）
│   ├── public/             ← 网页：index.html=员工端，admin.html=管理后台
│   └── data/               ← 运行后自动生成：db.json 数据 + backups/ 每日备份
├── 启动服务器(Windows).bat  ← 在 Windows 电脑上一键启动服务器
├── 员工打卡端.bat           ← 放到员工电脑上，双击打开打卡窗口
└── docs/云端控制中心-部署与扩展计划.md  ← 部署到云服务器的完整计划（可交给 ChatGPT 执行）
```

## 🚀 方式一：先在店里的一台电脑上跑起来（局域网，今天就能用）

适合：所有打卡电脑和这台电脑连的是**同一个路由器 / WiFi**。缺点：只能在店里看后台，这台电脑要一直开着。

1. 在当服务器的那台电脑上安装 **Node.js**：打开 <https://nodejs.org/zh-cn>，下载 **LTS 版本**，一路「下一步」安装即可。
2. 双击 **`启动服务器(Windows).bat`**，会出现一个黑色窗口，里面写着：
   - **终端激活码**（例如 `ABCD-1234`）：员工电脑第一次打开时要输入
   - **初始化码**（6 位数字）：第一次进管理后台时要用
   - 如果 Windows 弹出防火墙提示，点「**允许访问**」
   - ⚠️ 这个黑色窗口**不要关**，关掉员工就不能打卡了
3. 在这台电脑的浏览器打开 **<http://localhost:8080/admin>**，输入初始化码，设置你的管理员密码，然后在「员工」页添加员工。
4. 查这台电脑的局域网 IP：按 `Win + R`，输入 `cmd` 回车，再输入 `ipconfig` 回车，找到「IPv4 地址」，比如 `192.168.1.100`。
5. 员工电脑：用记事本打开 **`员工打卡端.bat`**，把 `set "SERVER=http://localhost:8080"` 改成 `set "SERVER=http://192.168.1.100:8080"`（换成你的 IP），保存。然后把这个 bat 复制到每台员工电脑上，双击打开，输入终端激活码即可。

> 💡 建议在路由器里给服务器电脑设置「固定 IP」，不然 IP 变了员工电脑就连不上了。

## ☁️ 方式二：部署到云服务器（在哪都能看后台）

把 `server` 文件夹放到云服务器上运行，你在家用手机也能看打卡情况。具体步骤见 **[docs/云端控制中心-部署与扩展计划.md](docs/云端控制中心-部署与扩展计划.md)**，可以直接把整份文档发给 ChatGPT，让它一步步带你操作。

## 📏 规则

- **没有休息日**，每天都需要打卡。**日薪 = 月薪 ÷ 当月天数**（30 天的月份日薪 ¥100，31 天的月份日薪 ¥96.77），整月正常出勤刚好拿满月薪

| 上班卡 | 任务完成卡 | 当日工资 |
|---|---|---|
| 11:00 之前 | 16:00 之前 | ✨ 全薪 |
| 11:00 及之后 | 16:00 之前 | 🌤️ 半薪 |
| 11:00 及之后 | 16:00 前未完成 | 🌧️ 无薪 |
| 11:00 之前 | 16:00 前未完成 | ⏳ 默认半薪（后台可改成全薪或无薪） |
| 没打上班卡 | — | 💤 缺勤，无薪 |

- **提成** = 当月业绩合计 × 提成比例。默认比例 0%（现在没有提成就不用管）；以后在「设置」里改默认比例，或在「员工 → 编辑」里给某个人单独设置。业绩在后台「业绩提成」页录入
- **每月 15 日**自动结算**上一个自然月**的工资（基本工资 + 提成），记录永久保存。标记「已发放」后锁定
- 以上时间、发薪日、比例都能在后台「设置」里修改

## 🔐 安全设计

- 员工端**没有任何修改功能**；补卡、改规则、改工资都只能在管理后台做，需要管理员密码
- 每次补卡必须填写原因，所有后台操作都记录在「日志」里（谁、什么时候、从哪个 IP、改了什么）
- 打卡电脑需要**终端激活码**才能使用，激活码可以在后台随时更换
- 员工可以设置**打卡密码**防止代打卡（后台「员工 → 编辑」）
- 打卡时间以**服务器时间**为准

## 💾 数据与备份

- 数据保存在 `server/data/db.json`，服务器**每天自动备份**到 `server/data/backups/`（保留 90 天）
- 后台「设置 → 下载完整备份」可以随时下载一份到自己电脑上
- 换电脑或换服务器时，把整个 `server/data` 文件夹复制过去就行
- 旧版（单机版）导出的备份文件可以在「设置 → 从备份恢复」导入
