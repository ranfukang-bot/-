# ✦ 星光打卡 · 员工考勤与工资系统

给小团队用的 Windows 电脑打卡软件。**不用安装、不用联网**，双击就能用；打卡、算工资、发薪记录全自动，打卡还有满屏烟花和金币雨。

## 🚀 怎么打开

1. 把整个 `clock-in-app` 文件夹复制到电脑上（比如桌面）
2. 双击 **`启动打卡系统.bat`**
   - 会用 Edge（没有 Edge 就用 Chrome）以「独立窗口」打开，看起来像一个独立软件
   - 也可以直接双击 `index.html` 用浏览器打开
3. 第一次打开时输入员工姓名，就能开始打卡

> 💡 想放到桌面：右键 `启动打卡系统.bat` →「发送到」→「桌面快捷方式」。

## 📏 打卡与工资规则

| 上班卡 | 任务完成卡 | 当日工资 |
|---|---|---|
| 11:00 **之前** | 16:00 **之前** | ✨ **全薪**（正常出勤） |
| 11:00 **及之后** | 16:00 **之前** | 🌤️ **半薪** |
| 11:00 **及之后** | 16:00 前未完成 | 🌧️ **无薪** |
| 11:00 **之前** | 16:00 前未完成 | ⏳ 默认**半薪**（原规则没提到这种情况，可在「管理」里改成全薪或无薪） |
| 没打上班卡 | — | 💤 缺勤，无薪 |

- **日薪 = 月薪 ÷ 当月应出勤天数**，整月正常出勤刚好拿满 ¥3000
- 默认周一到周五是工作日，周末不计考勤（「管理」里可以勾选周六、周日）
- **每月 15 日**自动结算**上一个自然月**的工资，生成的记录会一直保存（例如 10 月 15 日结算 9 月工资）
- 结算记录点「发放」后会锁定；没发放前，管理员补卡后结算金额会自动更新

上面的时间点、发薪日、月薪都能在「管理 → 规则设置」里修改。

## ✨ 功能一览

- **⏰ 打卡**：实时大时钟；离 11:00 和 16:00 截止还剩多久的倒计时；时间轴；上班卡和任务完成卡（完成时可以写一句今天做了什么）
- **🎉 情绪价值**：准时打卡放烟花和彩带；准时收工下金币雨，弹窗里的收入数字会一路跳到最终金额；迟到也有暖心鼓励；配音效（右上角可以关）；每天的励志语录
- **📅 考勤日历**：每天的状态一眼就能看清（颜色区分），点日期看详情；管理员可以补卡（每次修改都留记录）；可以导出当月考勤表（CSV，用 Excel 打开）
- **💰 工资结算**：本月实时累计、下次发薪倒计时、历次发薪记录、一键标记已发放、工资条（可打印）、导出全部结算记录
- **🏆 荣誉榜**：月度准时之星领奖台、连续出勤天数 🔥、11 枚成就徽章（早起的鸟儿、全勤之星、传奇打工人……）
- **🔐 防代打卡**：每个员工可以设打卡密码；管理区可以设管理员密码
- **💾 备份**：一键导出 / 恢复全部数据

## ⚠️ 注意事项

- 数据保存在**这台电脑的浏览器**里。请固定用同一个浏览器打开（用 bat 启动就不会出错），**不要清除浏览器的「Cookie 和网站数据」**
- 建议**每月发薪后点「导出完整备份」**，把备份文件存到 U 盘或网盘
- 打卡时间以电脑系统时间为准，建议设置管理员密码，避免有人改电脑时间
- 这是单机版，多台电脑之间的数据不会互相同步
